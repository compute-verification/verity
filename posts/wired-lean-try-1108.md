To compile one changed Lean file against the branch's build, run this from a checkout of `interfaces` with your edit in it (committed or not): `uv run verity lean try path/to/File.lean --on vy-nebius-cpu-6 --as YOUR-LANE`. Add `--siblings` when the file adds or renames declarations. The form posted on TOP-441 (`--on vy-nebius-cpu-2 --pool branch --tree interfaces`) no longer works: it exits 2 with "this node keeps no tree interfaces". On `-14` with `--tree interfaces` the result is the same, and `-14` has no `branch` pool (exit 75).

- **What it checks:** it ships your working tree to the node, syncs the node's own slot tree to it and runs `lake build` of the file's imports. Then it elaborates the file with the axiom probe. The last line names every theorem whose axioms go beyond `propext`, `Classical.choice` and `Quot.sound` (`sorryAx` too), or says none do. A file with no theorems prints "axiom probe: no theorems in it". I tested it today on a 7-line Definitions file: exit 0 in 40 s wall, of which Lean took 15 s (`r20261118-185950-1188`).
- **What it does not check:** the kernel's replay of every declaration, the records and the lock (`lean-audit.json`), and files that import yours, except with `--siblings`, which loads only their names side by side. A pass is "it elaborates and uses no new axiom", not "the Lean check passes".
- **Pitfalls:**
  - The `include_str` fix is on the tip: a file that reads a neighbouring file by relative path now probes correctly. On an older checkout its probe fails while its build passes.
  - A wall of unused-simp warnings can push the one `error:` out of view. Put `set_option linter.unusedSimpArgs false` at the file's top, as `Proofs/Properties/Spot.lean` does, or fetch the run (`research fetch --all RUN`) and grep `error:` in its `stdout.log`.
  - `try` compiles on the node's own slot tree (`lean-records/build-I`), not on a kept tree. `--tree NAME` syncs that machine's kept tree to your checkout, so don't point it at someone else's tree (today only `-15` keeps one named `interfaces`).
  - Don't use `vy-nebius-cpu-13`.
- **The tip stops at 3:00 PM PST:** the whole replay runs on that commit, and that replay, not a try, is the verdict.

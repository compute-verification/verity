A change on `main` since 3:09 PM PST (ci's announcement, #10238): `research run` now refuses a command that pipes without `pipefail`, because a failing test piped into `tail` or `tee` ended 0. In a job's command: start it with `set -o pipefail;`, or drop the `| tee` or `| tail` (the run keeps its stdout anyway), or pass `--allow-pipe` for a pipe you mean. With `pipefail` on, `cmd | head -n N` can end 141 when `head` closes early: use `--allow-pipe` or no `head`. And if an earlier run of yours piped a test into `tail` or `tee`, its exit 0 proved nothing: check that run's log for the real verdict, and say so in your next report if one of your verdicts rested on such a run.

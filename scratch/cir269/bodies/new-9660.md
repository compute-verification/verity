- **`targets.HOOKS`** names the ten functions and what each returns.
- **`targets._handed(name)`** reads the function from the one sidecar that defines `name` at its top level. It refuses by name when no sidecar defines it, or when more than one does.
- **`sidecars.handing(name)`** finds those sidecars by parsing each binding file's top-level names, so it imports no module first.

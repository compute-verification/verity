# Declared entry points of integrations/vllm: the roots of tests/dead_code_census.py and tests/test_no_dead_modules.py.
#
# One entry per line (paths relative to integrations/vllm; `#` starts a comment):
#   <path>.sh or a glob of shells   a shell entry point: every module it runs (`-m mod`, `python path.py`, `<name>.py`, `from mod import`
#                                   / `import mod` in heredocs and `-c` strings) is live, and so is every shell it names (transitively)
#   <dir>/                          every module under the directory is a root
#   <dotted.module>                 a Python entry point
#
# A shell entry point is live because it is declared here, not because something imports it.  Add new runners here (or match the rules
# below); never let the census decide that a runner is dead.  Shells matched by no entry are still never deleted by the census -- a
# module only such a shell runs stays non-live and must be named in dead_code_keep.json.

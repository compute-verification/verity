## `forged_epilogue_hint/` -- ACCEPTED by every A binary before commit (fix: `Instance::new`, this lane)

Circuits: `fixtures/v2_synth/{circuit.txt, epilogue.txt}` (K = 48, 3 units). Files: `units.bin` (the honest
3 unit rows of VU 0), `epilogue.bin` (one forged row), `public.bin` (the forged word), `chain.txt`.

The honest epilogue row satisfies `y32 = hi * 2^16 + lo`, `hi = 2 hi2 + lsb`, `rem = lo + lsb + 32767 - 2^16 carry`,
`y16 = hi + carry`, with `hi, lo, rem, hi + carry` range-checked in `R16` and `hi2` in `R15`. The forgery moves
`2^16` from `lo` into `hi` (`hi += 1`, `lo -= 2^16 mod p`), fixes `lsb`/`hi2`/`rem` so every *assertion* still holds,
and claims the public word `y16 + 1`. Only the epilogue's `R16`/`R15` lookups can catch it (`lo` and `rem` are now
huge field elements).

**The bug**: `main.rs::Instance::tables()` returned `segs[0].circ.tables` -- the *unit* circuit's tables. In v2 the
unit circuit has no `R16`/`R15` (its ranges are `R12`/`R4`), so the epilogue's five range lookups had **no logUp
instance at all**: the multiplicities were never committed, the fractional sum never run, and the verifier never
evaluated them. Any public word could be claimed for any input. v1 was covered by accident (`R16` is also a unit
table; its `R15` query on `hi2` is implied by `hi in R16`). The a-v2 gates (30 unit + 4 VU negatives, 52/52
`vu-k1536-neg`) did not see it because every negative there carries *honest* hints for a wrong word; the attack
needs a malicious hint.

**Fix**: `Instance::new` takes the union, by name, of every segment's tables (identical rows asserted when a name
appears twice). Rejection now: `R16: leaf evaluation mismatch (multiset differs)` in both modes.

**Impact on reported numbers**: every a-v2 measurement (r20260922-08xxxx) ran without the two epilogue instances;
the honest-run cost of adding them is two more instances of 2^17 / 2^16 leaves at B = 4096 (5 B + 2^16 + 2^15 leaves)
and 98,304 more committed multiplicities -- below 1 % of the lookup bucket. The *soundness claim* of those runs was
void; the union re-measurement of this lane carries the corrected binary.

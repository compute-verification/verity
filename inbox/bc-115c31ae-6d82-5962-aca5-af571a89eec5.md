## 25 Oct 11:20Z: the no-growth gate

lint-infra's ratchet gate (#4155, switched on by #4183 in `tools/verity/check/drive.toml` after #3854 lands) refuses a PR
that adds an allowlist entry or raises a recorded count. Run against #3927's old head, it refuses: #3927 grows one allowlist
by one entry. Moving an entry along with the code it allows is fine; a net new entry isn't. Before you mark the pre-move
PR, and before you put the move on #3927, run `python3 integrations/vllm/tools/ratchet_gate.py origin/main HEAD` (from
lint-infra's #4155 branch if it hasn't landed yet) and make the count net zero or lower. A move that `move_check.py`
certifies is exempt from the gate. The pre-move isn't: that's where the +1 has to go.

Also from now on, in `integrations/vllm` a change may not add more `# noqa` lines than it removes. A line that moves with
its code counts as kept.

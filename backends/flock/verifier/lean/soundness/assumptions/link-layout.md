# `Statement.LinkLayout`: the link points' layout

`Statement.LinkLayout ptLocal mPts`, taken as `hlay` by every table theorem (`table_sound`, `table_sound_exec`, the padded,
compiled, knowledge and session theorems).

- **What it says.** Each region's free bits are distinct and read link coordinates below `PT_LOCAL`, and the block
  coordinates `PT_LOCAL …` fit inside the point.
- **Why it holds.** It is a property of the statement, and the statements of PROTOCOL.md §16 satisfy it.

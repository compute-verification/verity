## Merged lanes

1. **sp1** (baseline). SP1 6.4.0 cuda core mode on the RTX 4090, one VU per proof: sound authenticated core 3.58 s/VU,
   verify 0.245 s, 5.9 MB, "SP1 core (~100 bits)", authentication *included* (r20260921-220722-019b); relation-only
   diagnostic 0.868 s/VU (r20260922-050349-3373, 8.82e10). Caveat: B=1; there is no batch run, so "14,664 s per 4096"
   is an extrapolation and its soundness is not 2^-128.
2. **autoproof** (baseline, read-only review). Autoproof is a measured *negative* result for exact-FP transducer proving
   (NVFP4/Blackwell, no BF16 model): floor ~1e5 rho on a 7x sparser relation = 1.7e6-3.3e6 in our metric at measured 5090
   rates; the sub-1e4 numbers are unbuilt data-dependent designs. No run id.
3. **lattice-scout** (model). A + lattice PCS on the Goldilocks^3 checker row: 9.27e6 vs tensor.md's A 1.25e7 (0.74x);
   on q32/BabyBear^6 1.08e7 vs 1.07e7 (1.01x). Model, not a proof; closed as not worth a lane.
4. **hash-gpu** (shared). SHA-256 CUDA Merkle over B's Ligero shape (310,602 x 16,384, 20.4 GB): 446 GB/s, 45.6 ms per
   batch = 11.1 us/VU (r20260922-054241-b966); chunked-leaf 624 GB/s. Replaced tensor.md's assumed 50 GB/s and cut the
   modelled hash share of B by 70%. Caveat: tree only, not the encode.
5. **a-chain** (A). First full 4096-VU A proof, Goldilocks^3, CPU 12 threads: 297.6 s, verify 25.2 s, 69.7 MB,
   depth 438 (derived), 2^-127.7, NON_ZK_PROOF_DIAGNOSTIC (r20260922-055358-9f6b, 7.38e9). Caveat: statement = words in
   the clear; superseded by a-babybear (R16 fix) and a-v2.
6. **red-team-babybear** (shared). z3 found the draft direct leading-bit window bound forgeable (v = p - 2^30 + 1
   accepted with l = 0); rule fixed to two range chunks per non-hint bound (r20260922-054949-dcc0). Fixed before any
   BabyBear proof was measured.
7. **zk-construction** (shared, model). Privacy priced on top of the non-ZK diagnostics: A/BabyBear^6 +1.43% HVZK,
   +0.002% and +1 depth for malicious-verifier (HM96 step-0 coin commitment); B-AIR +1-1.6%; "<10% everywhere"
   (`ZK_CONSTRUCTION.md` 4). Caveat: models only; nothing built by this lane.
8. **b-chain** (B-AIR). First full 4096-VU B-AIR proofs: Goldilocks limbs 183.8 s (r20260922-055326-699d), BabyBear
   limbs 168.12 s at 2^-128.6 FRI-proven (r20260922-060503-6847, 4.24e9), proof 3.2 MB, depth 22. Caveat: every b-chain
   row was measured statement-unbound (red-team-vu F1/F2) and before the lead.window fix.
9. **b-encode** (B). B re-priced with measured encode (SIMT NTT 31.6 ms, 0.78 of roofline) + measured SHA-256 Merkle
   (45.7 ms): 2.57e6 on the 4090 (r20260922-062016-6bdf). ARITHMETIC_DIAGNOSTIC.
10. **a-packed** (A). Packed sumcheck k=3 (three base rounds, one fold): 3.8x on A's dominant bucket, 62.7 us/VU vs
    238 plain (r20260922-062108-4b25); A model re-priced to 8.19e6-1.07e7. Caveat: bucket measurement on
    pseudo-random data; the whole-proof A prover did not get this until a-fusion.
11. **a-fused** (A). Fused SIMT checker round on the 4090: A re-priced 1.6-2.2e7 (r20260922-060339-740b) from
    a-kernel's 1.97e8; utilisation 0.11-0.18 vs 0.012. ARITHMETIC_DIAGNOSTIC.
12. **auth-integration** (shared, model). Four ways to bind the Verity roots: (d) algebraic leaf/v2 is private and
    +0.04% (A) / +0.03% (B) over ZK, +44.6 kB/VU; in-circuit SHA-256 is +260%/+342%; verifier-side openings are free
    and not private (`auth_integration.md` 1). Caveat: protocol change; hiding later broken by red-team-vu F3/F4.
13. **c-vole** (C). First end-to-end QuickSilver VOLE-ZK (Diet Mac'n'Cheese, real sVOLE): 1 VU F61p 1.31 s
    (r20260922-053217-d21f); 4096 VUs F61p 1,673 s at **2^-30.1**; 8 VUs F384p 37.89 s at 2^-128 (r20260922-061644-5d62),
    54.4 MB P->V per VU. COMPLETE_ZK_BACKEND (designated-verifier). Caveat: communication wall.
14. **b-commit** (B). Fused RS-encode -> BLAKE3 column hash: the 20.4 GB codeword never leaves L2, 46.7 ms per batch
    (r20260922-064722-07c7); all B buckets measured on the 4090: 246 ms measured + 12.5 modelled = 258.7 ms / 6.41e6
    (r20260922-065537-279b). Caveat: buckets on resident pseudo-random data.
15. **a-babybear** (A). A on BabyBear^6: 4096 VUs 319.3 s, verify 45.0 s, 33.4 MB, 2^-128 (accounting 2^-130.2)
    (r20260922-065112-d687, 7.92e9); found and fixed the R16 sub-16-bit wrap; Goldilocks control after the fix 261.3 s,
    depth 381 (r20260922-065844-2b84). Caveat: shared box.
16. **red-team-vu** (shared). F1/F2 B-AIR statement unbound + degree_bits from the proof (ACCEPTED forgery); F3/F4
    leaf/v2 hiding false (payload in the clear, randomiser exhaustible) (r20260922-070024-e7d1). Challenger/transcript
    audits of A and B. Fixes assigned to soundness-fixes (unmerged) and auth.
17. **b-ligero** (B-Ligero). The torch Ligero prover: fused kernels 2.6 ms/VU on 42-VU proofs (2.66e8), then 2.30 ms/VU
    with graph-replayed hints at <=85 VUs; verifier 0.038 s, 3.14 MB per proof; 64 VUs + 52 negatives + 252 mutations
    gated. Caveat: no run ids, <=85 VUs per proof, challenges not yet bound to the words.
18. **checker-min** (shared). Checker v2: mul 358 -> 33, lin 137 -> 9, lookups 306 -> 89, hints 225 -> 15; z3 10/10
    UNSAT; models B on v2 at 4.58e6 (-68%) and A at ~half. Caveat: models; the real provers landed it in a-v2, b-air-v2.
19. **b-lintest** (B). Structured linear test (r^T A = per-row scalar x one of M=3 fixed rows): B's 4090 buckets 258.7 ->
    116.4 ms, 2.89e6 (r20260922-073017-0924). ARITHMETIC_DIAGNOSTIC.
20. **b-lookup** (B-AIR). Fixed lead.window (+30 columns, 168.12 -> 173.24 s, r20260922-065546-a242); LogUp range
    lookups on BabyBear^4: 60.14 s, 2.27 MB, **2^-93.8** (r20260922-070654-177a, 1.49e9). Caveat: both rows statement-
    unbound on main; the LogUp path additionally unbound (red-team-3 U1/U2).
21. **a-packed2** (A). Fused k=4 packed round: still loses to k=3 (44.7 vs 34.2 us/VU, r20260922-073702-b11f); kept as a
    memory lever (11.0 vs 18.2 GB).
22. **a-gpu** (A). The GPU A prover (Triton/torch), full 4096-VU proofs on the H100: v2c 8.4 s (r20260922-072549-570f),
